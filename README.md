# Museo en orden — CREA-J 2026

Juego web educativo para relacionar 6 personajes salvadoreños con sus íconos y aportes.

## Características
- Funciona en computadora, tableta y celular.
- Se puede jugar arrastrando o tocando las fichas.
- No usa servidores, bases de datos ni librerías externas.
- Puede funcionar incluso sin conexión una vez descargado.
- Para publicarlo durante meses/años, se recomienda GitHub Pages.

## Publicarlo gratis con GitHub Pages
1. Crear una cuenta en GitHub.
2. Crear un repositorio nuevo, por ejemplo `museo-en-orden`.
3. Subir `index.html`.
4. Ir a Settings → Pages.
5. En "Build and deployment", elegir "Deploy from a branch".
6. Seleccionar `main` y `/root`.
7. Guardar. GitHub generará una dirección web permanente mientras el repositorio exista.

No hace falta instalar nada ni contratar hosting.
